= Machine Sensors MQTT Documentation
:doctype: book
:toc: macro
:toclevels: 2

== Overview
This document describes the MQTT topics used for publishing the state of sensors in different types of machines.

== Server
* URL: mqtt://broker.example.com:1883
* Protocol: MQTT

== Topics

=== Conveyor Belt

==== Topic: `conveyorBelt/{id}/sensor/LightBarrierFeedStation`
*Description*: Topic for publishing LightBarrierFeedStation sensor data of conveyor belts.

*Payload*:
[source,json]
----
{
  "value": "boolean",
  "timestamp": "string (format: date-time)"
}
----

This pages shows the configuration status of the factory.

This includes:

  • the status of the SCADA system
  • the status of the connected PLCs
  • the status of the machines (only those currently visible via their PLC). Each machine displays 2 informations buttons: its current status and the current command being executed.
  • Click on any button to obtain a textual description of each information displayed on the corresponding button.

Note: a machine may be active (ie. not idle) even if it is not currently executing a command as it might be still activating some engine (ex. a compressor)

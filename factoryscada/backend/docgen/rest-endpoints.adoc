= REST API of factoryscada backend

All paths are relative to the HTTP base URL of the backend (e.g. `http://localhost:9000`).

== Endpoints

[[rest_post-api-dynamic-mission-command-start-missionname]]
=== `POST /api/dynamic-mission/command/start/{missionName}`

Declared in `io.github.mbdo.factoryscada.frontend.controller.rest.DynamicMissionRestController.startMission()`

_Starts a dynamic mission by its (URL encoded) name. Answers 404 if the mission is unknown._

==== Parameters

- `missionName` (String, path variable)

==== Response

_202 Accepted: the mission is started asynchronously._

No body.

[[rest_post-api-dynamic-mission-command-stop]]
=== `POST /api/dynamic-mission/command/stop`

Declared in `io.github.mbdo.factoryscada.frontend.controller.rest.DynamicMissionRestController.stopMission()`

_Stops the currently active dynamic mission._

==== Response

_202 Accepted: the mission is stopped asynchronously._

No body.

_Sends a command to a machine running no mission, and waits for its feedback. Answers 409 if the machine runs a mission, 400 if the request is invalid._

==== Request Body

`MachineCommandRequestDTO`

[source,json]
----
{
  "type" : "object",
  "id" : "urn:jsonschema:io:github:mbdo:factoryscada:frontend:dto:replanning:MachineCommandRequestDTO",
  "properties" : {
    "command" : {
      "type" : "string"
    },
    "machine" : {
      "type" : "string"
    },
    "parameters" : {
      "type" : "array",
      "items" : {
        "type" : "object",

          "passable" : {
            "type" : "object",
            "id" : "urn:jsonschema:io:github:mbdo:factoryscada:core:Passable"

          "passableType" : {

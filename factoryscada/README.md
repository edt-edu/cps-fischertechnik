# FactorySCADA

WebUI to send commands to the rppmcontroller.

## Usage

Here is how you can run the project for development:

### Backend

```bash
cd backend
gradle :bootRun
```

### Frontend

Run `npm install` once before trying to start the frontend.

```bash
cd frontend
npm install
```

After that, start the frontend normally:

```bash
cd frontend
npm run start 
```
